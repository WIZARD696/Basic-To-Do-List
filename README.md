
# Basic To-Do List

A simple and interactive To-Do List web application built using **HTML, CSS, and JavaScript**.

This project was created as part of my journey to strengthen my fundamentals in **web development, JavaScript, DOM manipulation, event handling, and browser local storage**.

## 🚀 Features

* Add new tasks
* Store tasks using browser **Local Storage**
* Preserve tasks after refreshing the page
* Mark tasks as completed
* Simple and clean user interface
* Responsive design

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and layout
* **JavaScript** — Application logic and DOM manipulation
* **Local Storage** — Persistent task storage
